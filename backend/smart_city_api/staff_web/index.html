Когда и где пройдут работы

Жители увидят «Срок окончания уточняется». После начала работ вы сможете завершить их вручную в истории публикаций.

После публикации работа появится на главном экране выбранных домов. Уведомления отправятся сразу — даты выше обозначают время самих работ. Все даты указаны по московскому времени.

Куда отправить

Можно выбрать оба канала. В группу попадёт одно объявление, лично — по одному сообщению каждому получателю.

Кому отправить

Например: Солнечная, кв 9

Доступны только жители домов вашей УК. Личные объявления получают жители, открывшие бота и не отключившие уведомления.
