# Материалы дизайна

PNG-оригиналы актуальных логотипов и иллюстраций сохранены в Git для последующего редактирования и экспорта. Эта папка находится вне публичных файлов сайта и исключена из контекста Docker-сборок.

| Оригиналы | Изображения для мини-приложения |
| --- | --- |
| `source/brand/*.png` — светлый и тёмный логотипы | `mini-app/public/images/brand/*.webp` |
| `source/zhorik/*.png` — Жорик, дом и экраны загрузки | `mini-app/public/images/zhorik/*.webp` |

При изменении изображения сохраните оригинал здесь и обновите соответствующий WebP в `mini-app/public/images/`. Используемые приложением файлы перечислены в `mini-app/src/shared/ui/artwork-assets.ts` и `guide-assets.ts`.

Иконка iPhone остаётся в `mini-app/public/images/brand/app-icon.png`. PNG-изображения кабинета УК, включая Жорика с ноутбуком и Жорика для приглашений, находятся в `backend/smart_city_api/staff_web/assets/` и нужны во время работы кабинета.
