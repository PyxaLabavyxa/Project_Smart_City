# Домовед — мини-приложение

Приложение жителя для MAX на Next.js, React и TypeScript. Использует API из [backend](../backend/README.md). Запуск всего проекта в Docker описан в [DOCKER.md](../DOCKER.md).

## Запуск

Требуется Node.js 22.13 или новее. Выполните из каталога `mini-app`:

```powershell
npm ci
Copy-Item .env.example .env.local
npm run dev
```

Если `.env.local` уже существует, используйте его. Приложение доступно по адресу `http://localhost:3000`; API запускается отдельно.

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_API_BASE_URL` | Адрес API с `/api/v1`, по умолчанию `http://localhost:8000/api/v1` |
| `NEXT_PUBLIC_ENABLE_LOCAL_LOGIN` | Разрешает локальный вход при значении `true`; для публичной сборки — `false` |
| `NEXT_PUBLIC_SHOW_LOCAL_LOGIN_CONTROLS` | Показывает панель выбора локального пользователя при значении `true`; по умолчанию панель скрыта |

Для локального входа также включите `LOCAL_LOGIN_ENABLED` в backend, задайте `LOCAL_SESSION_SECRET` и выполните `python -m scripts.seed_local`. Используйте одинаковый hostname для приложения и API; адрес приложения должен входить в `CORS_ORIGINS`.

Переменные `NEXT_PUBLIC_*` встраиваются при сборке и доступны браузеру. После их изменения перезапустите dev-сервер или пересоберите приложение.

## Возможности

- Регистрация: ФИО, выбор УК, дома и квартиры. Состояние регистрации общее с ботом.
- Квартиры: добавление нескольких квартир и переключение между ними. Одна квартира может быть привязана к нескольким жильцам.
- Обращения: создание с фотографиями и местом на плане, фильтры, статусы и история.
- План дома: интерактивный фасад, выбор подъезда, этажа, квартиры и общей зоны.
- Сообщения: переписка между квартирами и чат с УК внутри своего обращения.
- ЖКХ: квитанции и передача показаний счётчиков одной формой.
- Камеры: просмотр кадров, добавление своей камеры по ссылке с автоматическим определением типа и проверкой кадра, выбор места на плане и фильтры «Мои камеры», подъезд, этаж, помещение.
- Здоровье дома: показатель по обращениям и история за 7, 14 или 30 дней. Нажатие на график выбирает дату.
- Контакты УК, информация о доме, обучение и переключение темы.

Раздел «План дома» открывает фасад по адресу `/house`, выбранный этаж — `/plan`. Контакты УК доступны на `/contacts`. Квитанции и показания переключаются вкладками в разделе «ЖКХ».

В разделе «Камеры» кнопка «Добавить камеру» открывает форму с тем же выбором места, что в обращениях. Панель фильтров изначально скрыта и открывается кнопкой «Фильтры»: доступны тип камер (все, мои, общедоступные), подъезд, этаж и помещение. Личная камера доступна только создателю сразу после добавления. Общедоступная камера до одобрения УК видна только владельцу; после одобрения — жителям этого дома. При отклонении владелец видит причину. Проверить решение можно в карточке камеры, обновить список — кнопкой рядом с количеством камер.

Вставьте публичную ссылку на камеру: тип подключения определится автоматически (снимки, RTSP/RTSPS, RTMP/RTMPS, HLS, MJPEG, ONVIF или HTTP-видео). Под полем отображается короткий статус проверки и полученный кадр либо ошибка с кнопкой повтора. Некорректная ссылка проверяется локально без запроса к серверу. Изменение ссылки и данных доступа запускает новую проверку; устаревшие ответы игнорируются. Тип можно указать вручную в дополнительных параметрах. Сервер подключается через изолированный camera-worker, логин и пароль вводятся отдельно и хранятся зашифрованными. Тестовые камеры используют локальные изображения.

Для двора, парковки и территории дома подъезд и этаж отключены и показывают «Нет подъездов» / «Нет этажей». При смене места несовместимые фильтры очищаются. У входной группы доступен только первый этаж. Эти правила общие для камер и обращений. Подъезд и этаж в формах создания выбираются обычными выпадающими списками без отдельного модального окна.

При первом входе без квартиры открывается регистрация. В тестовом режиме заявки принимаются автоматически. После привязки запускается обучение; повторный запуск доступен в разделе «Ещё».

В разделе «Ещё → Настройки» доступны светлая, тёмная и системная темы. Тема сохраняется в браузере. Настройки уведомлений MAX сохраняются в аккаунте отдельно для сообщений соседей, ответов УК, статусов обращений и объявлений. Рассылка общих объявлений пока не подключена.

При старте приложение загружает основные разделы, данные и изображения. Камеры подключаются при открытии их раздела. Черновик обращения хранится в памяти и сбрасывается при перезагрузке или смене квартиры.

## Сборка и проверки

```powershell
npm run lint
npm run typecheck
npm test
npm run build
```

[Dockerfile](Dockerfile) использует standalone-сборку Next.js. Маршруты находятся в `app/`, экраны и компоненты — в `src/`, статические файлы — в `public/`.

## Ограничения

Оплата ЖКХ демонстрационная: платёжный провайдер не подключён. Выбор СБП или карты не проводит оплату. PDF-квитанции и документы дома пока не загружаются; кнопки сообщают об этом. Если УК не указала дополнительные контакты, интерфейс показывает отсутствие данных. Доступность камер зависит от публичного источника и настройки camera-worker. Здоровье дома рассчитывается по доступным обращениям и не является показанием инженерных датчиков.
