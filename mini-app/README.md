# ДомПульс

Frontend приложения для обращений жителей. Next.js, TypeScript, CSS Modules.

На главной отображаются последние активные обращения. В разделе «Обращения»
доступны полный список, карточка с историей статусов и форма создания.
Есть светлая и тёмная темы. Главная и «Ещё» связывают разделы приложения.
На нижней панели доступны дом, обращения, план, камеры и дополнительные разделы.
Вложенные экраны сохраняют выделение своего раздела.

## Навигация

Разделы `/health`, `/messages`, `/info`, `/company`, `/cameras` и `/cameras/[id]`
доступны с главной страницы и из меню «Ещё».
Из плана можно перейти к созданию обращения или сообщениям.

Проверка связей:

- Главная → все обращения → карточка → план дома.
- Главная → сообщить о проблеме → создать обращение → карточка.
- Главная → план / камеры / здоровье дома / сообщения.
- План → создание обращения → отмена возвращает к плану.
- План → сообщения → «К плану дома».
- Ещё → информация о доме / управляющая компания → назад.
- Камеры → карточка камеры → все камеры; неизвестный ID даёт путь к списку.

Ссылки возврата ведут к явному разделу приложения и работают при открытии
страницы напрямую. Параметр `from=plan` или `from=company` у формы меняет
только возврат; произвольные внешние адреса не принимаются.

Backend не подключён. Начальный список использует тестовые данные из
`src/entities/issue/model/demo-issues.ts`. Новые обращения хранятся в памяти
до перезагрузки страницы и не отправляются в УК.

## Запуск

Требуются Node.js 22.13+ и npm. Из корня репозитория:

```sh
cd mini-app
npm ci
npm run dev
```

Приложение доступно по адресу http://localhost:3000.
Переменные окружения для текущей версии не нужны.

## Проверки и сборка

```sh
npm run lint
npm run typecheck
npm run build
```

Запуск собранного приложения:

```sh
npm start
```

## Структура

Проект организован по Feature-Sliced Design.

```text
app/            Маршруты Next.js
src/
  _app/         Корневой layout и глобальные стили
  _pages/       Экраны
  widgets/      Шапка и навигация
  features/     Создание обращения, переключение темы
  entities/     Данные и компоненты обращений
  shared/       Общие стили и дизайн-токены
```

Слои App и Pages названы `_app` и `_pages`, чтобы не пересекаться
с каталогами маршрутизации Next.js. Внешние импорты слайсов идут через `index.ts`.

Для ручной проверки: создать обращение, открыть его карточку и вернуться
к списку. Новая запись должна появиться на главной среди активных.
Проверить обязательные поля формы и отображение на ширине 320px.
