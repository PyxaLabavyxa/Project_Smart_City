# ДомПульс

Начальный каркас frontend: Next.js, TypeScript и App Router.
Есть общая шапка и рабочая нижняя навигация: Дом, Обращения, План, Ещё.
Разделы пока содержат только заголовки. Активный пункт определяется по адресу;
работают прямые ссылки, перезагрузка и кнопки браузера «Назад»/«Вперёд».

Кнопка «Тёмная тема» переключает оформление, сохраняя выбор при переходах между
разделами. После перезагрузки используется светлая тема. Для неизвестного адреса
показывается страница 404 со ссылкой на главную. API и данные пока не подключены.

## Запуск

Node.js 22.13+ и npm:

```sh
cd mini-app
npm ci
npm run dev
```

Открыть http://localhost:3000. Backend и переменные окружения пока не нужны.

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
```

## Структура — Feature-Sliced Design

```text
app/                              # Точки входа Next.js App Router
  layout.tsx
  page.tsx
src/
  _app/                           # Слой App: сборка приложения
    layouts/                      # RootLayout, metadata, viewport
    styles/                       # Глобальные стили
  _pages/
    home/                         # Главная
      index.ts                    # Публичный API
      ui/
    issues/                       # Обращения
    plan/                         # План дома
    more/                         # Ещё
    not-found/                    # Страница 404
  widgets/
    application-shell/            # Шапка, область контента, навигация
      index.ts                    # Публичный API
      ui/
  features/
    toggle-theme/                 # Переключение темы
  shared/
    styles/                       # Общие дизайн-токены
```

`app/` содержит только точки входа маршрутизатора. FSD-слои App и Pages
названы `_app` и `_pages`, чтобы не конфликтовать с маршрутизацией Next.js,
согласно [руководству FSD для Next.js](https://fsd.how/docs/guides/tech/with-nextjs/).

Импорты направлены вниз по слоям: App → Pages → Widgets → Features → Shared.
Можно пропускать слои. Внешний код импортирует слайсы через их `index.ts`,
внутри слайса используются относительные импорты. Shared не зависит от верхних слоёв.

Слой `entities` пока отсутствует: предметные данные ещё не подключены.
