# Домовед — оформление с логотипом друга

## Результат
Отдельный адаптивный пример интерфейса: главная в светлой и тёмной темах, обращения, создание обращения, ЖКХ, камеры, Ещё. В галерее gallery.html лежат готовые снимки; index.html открывает сам пример. Исходный рабочий проект не изменён.

## Логотип
В assets/ сохранены точные копии трёх предоставленных пользователем PNG: тёмный логотип, белый логотип и иконка. Буквы, персонаж, красная шапка и исходная альфа не перерисовывались. На главной и рабочих экранах используется полное написание. Иконка показана в «Ещё» и подключена как favicon. В белом исходнике есть мелкие неровности прозрачного края: для будущей публикации полезен чистый векторный экспорт того же утверждённого знака.

## Стиль
- Основа: глубокий сине-зелёный #0B3A4E, белый и фон #F5F8F8.
- Красный #ED4939 — только небольшой фирменный акцент в действии, шагах формы и выбранном разделе.
- Шрифт: локальный Onest из проекта, 15 px для основного текста.
- Основные интервалы 24–28 px, контроль от 44 px, главный CTA 50 px.
- Дом находится в отдельной области 120 px, не заходит на текст.
- На главной одна карточка актуального обращения; список и здоровье продолжаются ниже по прокрутке.
- Сервисы квартиры объединены в две строки.
- На списке, формах и квитанции нет повторяющегося декоративного дома.
- Нижняя навигация непрозрачная, контент имеет запас снизу; на форме отдельные действия.

## Проверка
Пример отрисован в изолированном браузере, снимки 390 × 844 CSS px при масштабе2 (PNG780 ×1688). Проверены страницы на ширинах390 и320: нет горизонтального переполнения, нет отсутствующих изображений и ошибок JavaScript. Проверены смена темы, навигация, поиск и переходы четырёх шагов формы. Все семь снимков осмотрены.

## Границы примера
Нет подключения к API. Обращения, денежные суммы и сроки — иллюстративные данные из предыдущих экранов. Заявки и показания не отправляются, платежи не проводятся. Ссылки на второстепенные функции открывают пояснения. Черновик сохраняется в памяти открытого примера, после обновления страницы значения возвращаются к демонстрационным. Камеры показывают исходные фотографии проекта, не прямой видеопоток.

Новые изображения генератором не создавались: утверждённые логотипы использованы напрямую, а PNG экранов получены из свёрстанного примера. Иконки интерфейса — небольшие SVG.

## Как открыть
Распаковать весь архив и открыть gallery.html для обзора либо index.html для просмотра интерфейса. Интернет и установка зависимостей не требуются. Кнопки темы, навигации и формы работают локально.
